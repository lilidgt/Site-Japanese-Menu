## Como rodar o projeto
Este sistema utiliza React no Frontend, Node.js no Backend e MySQL.

### 1. Banco de Dados
- Abra o MySQL Workbench.
- Importe o arquivo `banco_lissa.sql` para criar o banco de dados `japanese_foods` e popular a tabela `dishes`.
- Verifique se o seu usuário MySQL é `root` e a senha é `senha` (caso contrário, altere no arquivo `backend-lili/server.js`).

### 2. Backend (Node.js)
1. Abra um terminal na pasta `backend-lili`.
2. Rode o comando: `npm install`
3. Inicie o servidor: `node server.js`
- O servidor rodará em `http://localhost:3000`

### 3. Frontend (React)
1. Abra um novo terminal na pasta `crud-site-lili`.
2. Rode o comando: `npm install`
3. Inicie a aplicação: `npm run dev`
- O site abrirá no navegador.
